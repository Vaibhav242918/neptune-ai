# 🌌 Neptune AI - Executive Data Science & Machine Learning Command Center

Neptune is an advanced, sci-fi HUD (Heads-Up Display) desktop assistant and automated data science laboratory built with Python, PyQt5, Pygame, and Google Gemini. Designed with a Tony Stark/JARVIS-inspired aesthetic, it bridges real-time voice-activated operating system automation with enterprise-grade machine learning workflows.

---

## 🚀 Key Features

* **Sci-Fi Holographic HUD Interface:** Fully dynamic, theme-switching PyQt5 UI featuring audio-reactive plasma cores, rotating target reticles, radar scan beams, and live frequency spectrum bars.
* **Automated Data Science Engine:** 
  * Ingest and profile CSV datasets instantly with automated AutoEDA generation.
  * Execute an **AutoML Leaderboard Arena** (comparing Logistic Regression, Random Forest, and Gradient Boosting).
  * Run multi-dimensional outlier detection using **Isolation Forest**.
  * Perform automated preprocessing (missing value imputation & feature scaling), PCA dimensionality reduction, and SHAP-powered model explainability.
* **Interactive What-If Simulator:** Real-time model prediction playground equipped with dynamic sliders to test custom data inputs instantly.
* **Built-in Developer Tools:** Interactive Python REPL console, Live Data Matrix inspector, and local memory archiving.
* **Multimodal Voice & Vision:** Powered by `gemini-3.6-flash`, speech recognition, and desktop vision capture (F10 screenshot analysis).

---

## 🛠️ Tech Stack

* **Core Language:** Python
* **GUI Framework:** PyQt5, Pygame (Audio Mixer & Spectrum Analysis)
* **AI / LLM:** Google GenAI SDK (`gemini-3.6-flash`)
* **Machine Learning:** Scikit-Learn, Pandas, NumPy, Seaborn, Matplotlib, SHAP
* **Speech & Audio:** SpeechRecognition, Edge-TTS, PyAudio
